Project Title: 
The project title for interactive mobile friendly responsive map of Christchurch fruit trees  is selected as Fruit Finder.

Goal
The project goal is to develop a responsive map enabled web application that allows New Zealand citizens, residents, communities and visitors to easily search, find and view public fruit trees in Christchurch City and navigate to them using available transport methods including walking, cycling, public and private transport. This project aims to promote community resource sharing with ease in foraging  where users can efficiently search for fruit tree locations, view them clearly on an interactive map, and access accurate step-by-step directions to their chosen destination with a user-friendly and responsive experience across devices.

Target Audience
The target audience consists of New Zealand citizens, residents and visitors who are in Christchurch and value sustainability, local food sources and explore outdoors.
